# 한라 학과 체험

중고등학생이 별명으로 참여하는 한라대학교 학생 프로젝트입니다. 8개 분야에 공통 안내자 지우와 함께하는 6문항 시연을 제공합니다.

## 로컬 실행

저장소 루트에서 아래 명령을 실행한 뒤 http://localhost:8000/ 에 접속합니다.

```sh
python3 -m http.server 8000 --directory public
```

브라우저 기본 ES 모듈을 사용합니다. 별도 패키지 설치나 컴파일 과정 없이 Vercel이 public 디렉터리를 제공합니다. 모든 게임 화면은 하나의 경로에서 열립니다. 새로고침하면 시작 화면으로 돌아가며 별명과 선택 기록은 메모리에서 지워집니다.

## 콘텐츠 편집

[콘텐츠 편집 가이드](CONTENT.md)와 [행사·부스 가이드](EVENTS.md)를 참고하세요. 입력 검사는 콘텐츠 모듈을 불러올 때 수행합니다. 터미널에서는 다음 명령으로 확인합니다.

```sh
node --input-type=module < public/content.js
```

public/assets/campus.png와 jiwoo.png는 이 프로젝트용으로 직접 그린 가상 캠퍼스와 안내자입니다. 배경을 교체할 때는 문항의 background, 안내자를 교체할 때는 guide.portrait 참조를 수정하세요. 본문은 기기에 설치된 시스템 글꼴을 사용합니다.
